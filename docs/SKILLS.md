# AERGIS Engineering Skills

This repository stores the operational skills used to keep AERMOTUS/AERGIS development consistent and evidence-driven.

## Skills

- `.github/skills/aergis-development/SKILL.md` — implementation, debugging, refactoring, testing, and engineering workflow.
- `.github/skills/aergis-audit/SKILL.md` — full-project defect, architecture, reliability, and pre-release auditing.
- `.github/skills/aergis-ci-validation/SKILL.md` — GitHub Actions diagnosis, build/APK validation, and release gates.

## Source of truth
These files document the working protocol; the live repository, Git history, tests, GitHub Actions results, and physical-device evidence remain authoritative for whether work actually succeeded.

## Change policy
Update these skills when the AERMOTUS/AERGIS development protocol materially changes. Keep instructions concrete, testable, and compatible with the phone-only development constraint.
